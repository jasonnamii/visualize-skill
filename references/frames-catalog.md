# 20 Frames Catalog

각 프레임 = 정의·언제·쓰는순간·핵심·본질모션·노드/엣지/축·티어.

---

## TIER 1 — MOTION 필수 (5개)

### 1. 플라이휠 (Flywheel)
- **정의**: 선순환 구조. 무엇이 무엇을 다시 강화하는가
- **언제**: 아마존식 성장 구조 설명, 자기강화 루프 보여줄 때
- **쓰는 순간**: "이 사업 왜 커질수록 더 빨라짐?"
- **핵심**: 노드 4~6개 + 단방향 화살표 원형 배치
- **본질 모션**: 중심축 360° 회전 (15~30초/회전)
- **노드/엣지/축**: 4~6 / 각 노드 다음 노드 가리킴 / 1축(원형)

### 2. 루프 (Loop / Growth Loop)
- **정의**: 유입→활성화→공유→재유입 순환
- **언제**: 제품 성장·콘텐츠 확산·네트워크 효과
- **쓰는 순간**: "어떻게 자가 확산?"
- **핵심**: 입력→처리→출력→피드백
- **본질 모션**: 중심→외곽 나선 확산 (입자 흐름)
- **노드/엣지/축**: 4~5 / 순환 + 외부 입력 1개 / 1축

### 3. 퍼널 (Funnel)
- **정의**: 인지→유입→가입→전환→결제 단계별 누수
- **언제**: 마케팅·세일즈 전환율 진단
- **쓰는 순간**: "어디서 새는지?"
- **핵심**: 단계별 너비 = 잔존 비율 (8단계 초과 ✗)
- **본질 모션**: 상→하 입자 흐름 + 단계별 배출 애니
- **노드/엣지/축**: 4~6 단계 / 단계간 전환율 라벨 / 1축(수직)

### 4. 브리지 (Bridge / Transformation)
- **정의**: 현재 상태 → 전환 장치 → 목표 상태
- **언제**: 컨설팅·서비스 정의·변화관리
- **쓰는 순간**: "우리가 무엇을 어떻게 바꾸나?"
- **핵심**: 좌(AS-IS) · 가운데(전환) · 우(TO-BE)
- **본질 모션**: 좌→우 건너기 + 형태 변형
- **노드/엣지/축**: 3 영역 / 좌→우 전환 / 1축(수평)

### 5. Multi-Flywheel
- **정의**: 여러 플라이휠이 서로 물리는 구조
- **언제**: 플랫폼·복합사업
- **쓰는 순간**: "이 사업 왜 시스템적으로 가속?"
- **핵심**: 2~4개 플라이휠 + 축간 연결점
- **본질 모션**: 다중 축 회전 + 축간 영향선 펄스
- **노드/엣지/축**: 12~20 / 각 휠 내부 + 휠간 연결 / 다축

## TIER 2 — MOTION 권장 (7개)

### 6. Hook Model
- **정의**: Trigger → Action → Reward → Investment 4단계 순환
- **언제**: 리텐션·중독성·습관 설계
- **쓰는 순간**: "왜 안 돌아오지?"
- **핵심**: 4단계 + 가변 보상 강조
- **권장 모션**: 펄스 (단계 활성화시 깜빡임) - 자동재생 ✗

### 7. Two-sided Market
- **정의**: 공급자 ↔ 수요자 상호 강화
- **언제**: 플랫폼·마켓플레이스
- **쓰는 순간**: "닭-달걀 어떻게?"
- **핵심**: 2 그룹 + 중앙 플랫폼 + 양방향 가치 흐름
- **권장 모션**: 양방향 화살표 흐름 펄스

### 8. Experience Journey Map
- **정의**: 사용자 경험 흐름 + 감정 곡선
- **언제**: UX 개선·서비스 설계
- **쓰는 순간**: "어디서 이탈?"
- **핵심**: 시간축 + 단계 + 감정 곡선 + 이탈 포인트
- **권장 모션**: 감정 곡선 그리기 애니 + 이탈 포인트 깜빡임

### 9. North Star Metric 트리
- **정의**: 핵심 지표 → 하위 드라이버 분해
- **언제**: 성장 구조 설계·KPI 정렬
- **쓰는 순간**: "뭘 올려야 성장?"
- **핵심**: 1 NSM + 3~5 드라이버 + 9~15 input metric
- **권장 모션**: 호버 시 하위 가지 드릴다운

### 10. Unit Economics 트리
- **정의**: LTV, CAC, 마진 분해
- **언제**: 수익성 검증·투자 대응
- **쓰는 순간**: "이거 돈 되냐?"
- **핵심**: LTV / CAC = 3+ 시각화
- **권장 모션**: 숫자 카운트업

### 11. 가치사슬 (Value Chain)
- **정의**: 공급→생산→유통→소비
- **언제**: 산업 돈 흐름·병목 진단
- **쓰는 순간**: "어디서 마진 빠짐?"
- **핵심**: 5~7 단계 + 마진/병목 표시
- **권장 모션**: 흐름 입자 + 병목 정체 애니

### 12. 생태계 맵 (Ecosystem Map)
- **정의**: 사용자·파트너·공급자·기관·경쟁자 관계
- **언제**: 산업판 읽을 때
- **쓰는 순간**: "누가 누구를 움직이나?"
- **핵심**: 중앙 또는 다중 노드 + 영향선
- **권장 모션**: 노드 호버시 연결선 강조 (force layout 권장)

## TIER 3 — STATIC OK (8개)

### 13. 레이어/스택 (Layer Stack)
- **정의**: 인프라/시스템/서비스/경험 층 구조
- **언제**: 플랫폼·기술·조직 설명
- **쓰는 순간**: "이 사업 몇 층?"
- **핵심**: 3~5 층 + 상하 의존성

### 14. 피라미드 (Pyramid)
- **정의**: 하위 기반 → 상위 성과
- **언제**: 단계·우선순위·성숙도
- **핵심**: 3~5 단계 + 하위 면적 큰 삼각형

### 15. 매트릭스 (Matrix)
- **정의**: 2축 분류
- **언제**: 의사결정 (예: 임팩트×난이도)
- **핵심**: 2축 + 4사분면 + 항목 점

### 16. 포지셔닝 맵 (Positioning Map)
- **정의**: 시장 위치 (예: 품질×가격)
- **언제**: 브랜딩·전략 발표
- **핵심**: 2축 + 경쟁사 점 + 자사 강조

### 17. JTBD 맵 (Jobs-to-be-Done)
- **정의**: 고객이 해결하려는 일 중심 구조
- **언제**: PMF 이전 본질 정의
- **핵심**: Job + 상황 + 동기 + 결과 + 장애물

### 18. Capability Stack
- **정의**: 핵심 능력 층 구조
- **언제**: 경쟁우위 정의
- **핵심**: 3~5 능력층 + 조합 효과

### 19. Unbundling/Rebundling 맵
- **정의**: 기존 가치사슬 해체→재조립
- **언제**: 시장 재정의·파괴적 전략
- **핵심**: AS-IS 사슬 / 분해 / 재조립 결과

### 20. Strategic Control Point
- **정의**: 가치사슬에서 지배 포인트
- **언제**: 플랫폼·독점 전략
- **핵심**: 사슬 + 지배 노드 강조
